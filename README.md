# Calculator example

This repository now contains a small Python calculator module.

## Files

- `calculator.py`: basic calculator methods plus a safe arithmetic expression evaluator
- `test_calculator.py`: unit tests using Python's built-in `unittest`

## Usage

Run the calculator with an expression:

```bash
python calculator.py "2 + 3 * 4"
```

Or start it without arguments and enter an expression interactively:

```bash
python calculator.py
```

## Testing

```bash
python -m unittest
```
